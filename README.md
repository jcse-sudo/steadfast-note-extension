# Steadfast Note Extension

Steadfast বুকিং ফর্মের কাজ সহজ করার Chrome এক্সটেনশন — Jewellery Collection-এর জন্য।

## কী করে

- **মেসেজ:** সেভ করা Note মেসেজ এক ক্লিকে Steadfast-এর Note ফিল্ডে বসে (ডেলিভারি চার্জ ৭০/১৩০-র মেসেজ ডিফল্ট থাকে)।
- **অর্ডার:** এক্সটেনশনেই অর্ডার লিখে এক ক্লিকে Steadfast ফর্মের সব ফিল্ড ভরা যায় — নাম, ফোন, ঠিকানা, প্রোডাক্ট, COD (দাম + ডেলিভারি চার্জ অটো), Invoice-এ JC অর্ডার নম্বর। সাবমিট অটো হয় না।
- **রাইডার:** ডেলিভারি হওয়া অর্ডারের পেজে Rate rider-এ ক্লিক করলেই Excellent রেটিং + ধন্যবাদ মেসেজ বসে যায় — Submit আপনিই চাপবেন।

## ইনস্টল (প্রথমবার)

1. [Releases](../../releases/latest) থেকে সবচেয়ে নতুন `steadfast-extension-vX.X.X.zip` ডাউনলোড করুন।
2. Zip extract করুন — ভেতরে `Note/` ফোল্ডার পাবেন।
3. Chrome-এ `chrome://extensions` খুলে উপরে ডানে **Developer mode** চালু করুন।
4. **Load unpacked** → `Note/` ফোল্ডারটি বেছে নিন।

## আপডেট কীভাবে পাবেন

এক্সটেনশন প্রতি ৬ ঘণ্টায় GitHub-এ নতুন ভার্সন আছে কিনা চেক করে। নতুন ভার্সন এলে আইকনে **NEW** ব্যাজ আসবে আর পপআপে ডাউনলোড ব্যানার দেখাবে।

1. ব্যানারের **ডাউনলোড**-এ ক্লিক করুন (নতুন zip নামবে)।
2. নতুন zip extract করে পুরনো ফোল্ডারের জায়গায় বসান।
3. `chrome://extensions`-এ এক্সটেনশনের **Reload** চাপুন — হয়ে গেল।

> এটা পুরোপুরি অটোমেটিক নয় — Chrome শুধু Chrome Web Store থেকে ইনস্টল করা এক্সটেনশনই নিজে আপডেট করে। এখানে প্রতি আপডেটে ১টা ক্লিক + Reload লাগবে। সম্পূর্ণ অটো-আপডেট চাইলে Web Store-এ পাবলিশ করতে হবে (একবার $৫)।

## নতুন ভার্সন পাবলিশ করা (মেইনটেইনারের জন্য)

1. `Note/manifest.json`-এ `version` বাড়ান (যেমন 1.2.0 → 1.2.1)।
2. বদল কমিট করে GitHub-এ push করুন।
3. Tag দিন: `git tag v1.2.1 && git push origin v1.2.1`
4. GitHub Actions নিজেই zip বানিয়ে Release-এ আপলোড করবে।
5. ইউজারদের ব্রাউজারে ৬ ঘণ্টার মধ্যে NEW নোটিস আসবে।

## ফাইল

- `Note/` — এক্সটেনশনের আসল কোড (manifest, popup, content script, background)
- `.github/workflows/release.yml` — Tag দিলে Release বানানোর অটোমেশন
- `GITHUB-SETUP-BN.md` — GitHub-এ লাইভ করার ধাপে ধাপে গাইড (বাংলা)
- `V2-SUMMARY-BN.md` — ভার্সনের বদলের সারাংশ (বাংলা)
